Official University of Cambridge logo files go here (not committed to the website until added).

Download them from https://www.cam.ac.uk/brand-resources/logo/download (staff login),
following the University's logo guidelines, and save as:

  cambridge-logo.svg        full-colour logo, for light backgrounds (homepage)
  cambridge-logo-white.svg  reversed/white logo, for the dark footer

PNG also works: cambridge-logo.png / cambridge-logo-white.png.
The site shows each logo automatically once its file exists.
